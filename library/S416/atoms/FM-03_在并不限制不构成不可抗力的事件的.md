## 在并不限制不构成不可抗力的事件的情况下，下列事件或情况不构成不可抗力，除非受影响方能够明确证明该事件是由符合不可抗力条件的事件造成的：

  + 延迟向卖方集团交付施工设备和/或卖方项目；

  + 任何分包商或其他人员（买方集团除外）的履约延误；

  + 缺少或无法获得劳动力、机械、施工设备、卖方项目或供货，包括运输；

  + 施工设备、卖方项目的正常磨损和随机缺陷；

  + 资金不可用、资不抵债、无力支付或延迟支付，或影响一方的经济状况发生变化；

  + 除上述{{ref:FM-02}} a）以外的不利天气条件，包括季节性不利天气条件；

  + 受影响方可（i）合理预见和（ii）防止或防范的任何事件或情况；

  + 卖方集团的工厂或工厂、卖方项目或施工设备的故障；

  + 仅限于卖方集团的罢工或劳工骚乱，不属于全国性或地区性罢工；

  + 无法购买保险；

  + 市场条件的变化；和/或

  + COVID 19大流行病（或与之相关的任何流行病）；

  + 卖方未能获得和/或保持订单项下其有责任获得和//或保持的许可证、授权书、同意书、批准书、执照、签证、清关、证书或类似物品，除非其本身是由不可抗力造成的。
